# Segundo Cérebro: Python para Análise de Dados

## Tema e objetivo

Montar no NotebookLM um segundo cérebro sobre **Python para Análise de Dados**, com fontes confiáveis em vídeo, artigo e PDF, para aprender a manipular, visualizar e interpretar dados na prática.

## Fontes que entraram

1. **Vídeo — Python para Análise de Dados e Data Science (Rodolfo Moreira)**
   - Link: https://www.youtube.com/playlist?list=PLWMAkZq0y_ZPIY5jpXJAmTuFzlGXXC1UM
   - Por que confio: curso gratuito em português, dividido em várias aulas, foco prático em análise de dados.

2. **Vídeo — Curso de Python para Ciência de Dados (ICMC/USP)**
   - Link: https://www.youtube.com/playlist?list=PLFE-LjWAAP9Skog9YhRvuNBjWD724c32m
   - Por que confio: material acadêmico do grupo DATA do ICMC-USP, cobrindo NumPy, Pandas, visualização e EDA.

3. **Artigo — Como Usar Python para Análise de Dados (DIO)**
   - Link: https://www.dio.me/articles/como-usar-python-para-analise-de-dados-introducao
   - Por que confio: artigo publicado na própria DIO, cobre bibliotecas fundamentais (Pandas, NumPy, Matplotlib, Seaborn) e o fluxo de trabalho.

4. **PDF — Programação para Análise de Dados (Carlos Eduardo Leal de Castro)**
   - Link: https://www.zenodo.org/records/22776420
   - Por que confio: apostila acadêmica com DOI e licença Creative Commons, publicada no Zenodo (Ibmec/SP).

5. **Documentação — Pandas: 10 minutes to pandas**
   - Link: https://pandas.pydata.org/docs/user_guide/10min.html
   - Por que confio: documentação oficial da biblioteca Pandas, fonte primária mantida pelos próprios desenvolvedores.

### Resumo das perguntas

1. Qual é o fluxo básico para analisar um dataset em Python?
2. Como lidar com valores ausentes no pandas?
3. Qual a diferença entre `loc` e `iloc`?
4. Como criar visualizações simples com Matplotlib e Seaborn?
5. Quais boas práticas para organizar um projeto de análise de dados?
